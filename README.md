## Product Overview

Chief Architect Premier X15 brings the major stages of an architectural project into a single desktop environment. Residential and commercial designers can use it for planning, parametric modeling, BIM-based organization, 3D visualization, and construction-oriented deliverables.

This release includes ray tracing, AI-assisted lighting, VR export, and cloud annotation. These capabilities support design review, coordination, space evaluation, and the preparation of documentation without requiring users to move between as many separate tools.

## Working with the Application

A normal project sequence begins with a new plan or imported source file and continues through modeling, visualization, and documentation.

- Create a floor plan or bring in an existing design
- Place building elements and modify them through parametric controls
- Apply AI-assisted lighting and ray tracing to presentation views
- Produce a walkthrough for client-facing review
- Export documentation and VR-ready files when needed
- Use cloud annotation to exchange notes during collaboration

### Example Project Flow

1. Open a new project.
2. Import Revit or SketchUp content when necessary.
3. Adjust the geometry, room arrangement, and design constraints.
4. Render selected views or process several outputs in a batch.
5. Complete compliance checks before producing the final deliverables.
